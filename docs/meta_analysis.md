# Pooling the bias across engines: a random-effects meta-analysis

Generated by `meta_analysis.py` from the committed scores for 3 independent TTS systems (gTTS, eSpeak, MMS), isolated-word condition. The effect size is **Cliff's delta** (African vs English CER), a rank-based, scale-free measure that is comparable across engines even though their absolute CER scales are not (espeak and isolated MMS saturate the ASR metric). Each engine's within-system uncertainty is a seeded bootstrap standard error (2000 resamples); the engines are combined with a DerSimonian-Laird **random-effects** model.

## Pooled (random-effects)

**Combined Cliff's δ = +0.426** (95% CI [-0.068, +0.920], medium effect), pooling 3 engines.

- **Heterogeneity:** Q = 24.77 on 2 df (p < 0.001), I² = 92%, τ² = 0.173.

The pooled interval includes zero, so the *combined* estimate is not on its own conclusive — read it alongside the clean-baseline engine. Every engine points the same way (δ > 0). But heterogeneity is high (I² = 92%): the engines are **not** estimating one common number. This is expected and is the point of using a random-effects model — magnitude tracks baseline quality (a clean-baseline engine shows a large delta; a metric-saturated one a small delta), while direction is consistent. The honest reading is a consistent *direction* with engine-dependent *magnitude*, not a single universal effect size.
