# Robustness: is the bias just a name-length effect?

Generated by `length_confound.py` from the committed scores (gTTS isolated, the clean-baseline run). Character length = letters in the name.

**1. Are African names longer?**

- English: median 6.0, mean 5.85 characters.
- African: median 6.5, mean 6.63 characters.
- African > English length: Mann-Whitney U **p = 1.48e-02** (yes, slightly longer).

**2. Does CER track length?**

- All names: Spearman ρ = +0.090 (p = 4.26e-01, n = 80).
- Within African names: ρ = -0.161 (p = 2.20e-01, n = 60).
- Length does **not** predict CER.

**3. Does the gap survive at matched lengths?**

- Overlapping length band: 4–9 characters (English n = 20, African n = 59).
- In-band mean CER: English 0.006 vs African 0.367.
- African > English CER in-band: **p = 1.07e-08** (gap persists).

**Conclusion.** African names are marginally longer, but length does not predict CER and the English–African gap persists at matched lengths — the disparity is driven by name origin/phonology, not string length.
