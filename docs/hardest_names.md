# Which names are hard across independent systems?

Generated by `hardest_names.py` from the committed scores for three independent engines (gtts, espeak, mms), isolated-word condition. Each name is ranked **within its own engine** as a percentile (0 = easiest name in that run, 1 = hardest), which is immune to the ASR-metric saturation that inflates espeak and isolated-MMS CERs. A name's consensus difficulty is its mean within-engine percentile.

**Across engines, African names rank harder than English ones:** mean consensus percentile 0.52 vs 0.27. The bias is not an artefact of a single system.

**But difficulty is only partly intrinsic to the name.** The top third (percentile ≥ 0.67) of *all 3* engines contains **1** of the 60 African names, and at least two engines' top third contains **12** — so a sizeable group is broadly hard, yet most names that break one system are handled better by another. There is no single set of universally 'unpronounceable' names; the bias is a population-level property (consistent with the moderate cross-engine rank correlation in `cross_engine.py`).
