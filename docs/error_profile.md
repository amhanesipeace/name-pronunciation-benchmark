# What kind of error is the bias? (CER decomposition)

Generated by `error_profile.py` from the committed scores (gTTS isolated, the clean-baseline run). Each name's CER is traced back into the edit operations that produced it — substitutions (a character heard as a different one), deletions (a character of the name dropped), and insertions (a character not in the name added). The three *rates* sum to the group's character error rate.

| Group | n | CER | sub rate | del rate | ins rate | error mix (S/D/I) |
| --- | --: | --: | --: | --: | --: | --- |
| English | 20 | 0.009 | 0.009 | 0.000 | 0.000 | 100% substitution / 0% deletion / 0% insertion |
| African (all) | 60 | 0.354 | 0.229 | 0.023 | 0.103 | 65% substitution / 6% deletion / 29% insertion |
| Yoruba | 20 | 0.363 | 0.260 | 0.014 | 0.089 | 72% substitution / 4% deletion / 25% insertion |
| Igbo | 20 | 0.314 | 0.204 | 0.044 | 0.066 | 65% substitution / 14% deletion / 21% insertion |
| Hausa | 20 | 0.391 | 0.217 | 0.009 | 0.165 | 56% substitution / 2% deletion / 42% insertion |

**Reading it.**

- English names are essentially error-free (CER 0.009), so there is no meaningful error structure to decompose on that side — the asymmetry itself is the finding.
- The African-name gap is dominated by **substitutions** (65% of all errors): the recogniser mostly hears *different* characters, not a shortened or padded version of the name.
- **Insertions** account for 29% of African errors — the character-level signature of a name being *expanded into other words* (extra sounds the name never had), consistent with the English-word substitutions quantified in the error taxonomy.
- **Deletions** are rare (6%): names are not simply being clipped or dropped; they are being re-pronounced as something else.

**Why it matters.** Two systems can share a CER yet fail differently. A deletion-heavy failure looks like *under-articulation* (syllables lost); a substitution/insertion-heavy failure like this one looks like *mis-identification* — the name is confidently pronounced as a different, more familiar word. That distinction matters for both diagnosis (where in the pipeline to intervene) and harm (a name turned into an unrelated English word is a different experience from a name trailing off).
